# 潮汐方舟 — 故事脚本 v0.2

> 世界观见《设计文档》§13。本文件是剧情的唯一来源：章节、角色、每个剧情弹窗的台词都以这里为准，`game.js` 的剧情表照此实现。
> 眼镜屏幕的限制：每页弹窗 ≤ 4 行、每行 ≤ 16 个汉字；一个剧情节点 ≤ 3 页。台词要短，说一件事。

## 一、主题

**水不该是用来收费的东西。**

主角因为交不起「水费」被城邦赶到外海；全剧的终点是亲手造出能让所有人免费喝水的方舟，然后决定要不要把它公开。
一路上遇到的人，几乎都是被同一套水费制度甩出来的人。
