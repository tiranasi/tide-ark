# 潮汐方舟（Tide Ark）— 设计文档 v0.1

> **历史文档。** 这里的实时天数、准星打捞、连按撬锁已在 v0.4 改为行动力、回合制打捞和一次开箱，现行规则见《[系统设计](系统设计.md)》§v0.4 与《[交互设计](交互设计.md)》§0。

> 原创末世漂流生存经营小游戏，运行在 Rokid Glasses（单色绿光，AIUI 技术栈）。
> 借鉴的是"末世漂流 + 打捞 + 建造庇护所"这一**玩法类型**；名称、美术、数值、关卡均为原创，不复刻任何现有游戏。
> 名称为暂定，可随时替换（只需改 `agent/app.json` 与 `agent/AGENTS.md`）。
>
> 文档分工：本文件 = v0.1 已实现的玩法 + 世界观（§13）；[故事.md](故事.md) = 完整剧情脚本与台词；[系统设计.md](系统设计.md) = v0.2 新系统与数值。三者冲突时，剧情以《故事》为准，数值以《系统设计》为准。

## 1. 一句话

大洪水之后，你守着一座漂浮庇护所：出海打捞废料、滤芯、宝箱和电鳗，用电鳗发电驱动海水过滤器产出淡水，一层层加高庇护所，熬过每晚的风暴潮，最终把它建成"方舟"（庇护所 Lv8）。

## 2. 核心循环

```
出海打捞 ──> 废料 / 滤芯 / 电鳗 / 宝箱 / 淡水
   │                         │
   │                 开宝箱（随机奖励）
   ▼                         ▼
建造与升级：庇护所 · 海水过滤器 · 电鳗发电机
   │
   ▼
夜间产出：电鳗 → 电力 → 过滤器 → 淡水（v0.4 起；最初是实时产出）
   │
   ▼
每日结算：消耗淡水 + 风暴潮伤害（庇护所等级越高越安全）
```

## 3. 资源

| 资源 | 符号 | 来源 | 用途 |
|---|---|---|---|
| 废料 | `#` | 打捞、宝箱 | 所有建造/升级、修补 |
| 淡水 | `≈` | 过滤器产出、打捞水瓶、宝箱 | 每日消耗、升级庇护所 |
| 电力 | `ϟ` | 电鳗发电机 | 让过滤器满速运转 |
| 滤芯 | `◇` | 打捞、宝箱 | 升级海水过滤器 |
| 电鳗 | `∿` | 打捞（稀有）、宝箱 | 升级电鳗发电机（每级安置 1 条） |

单色屏上资源靠"符号 + 文字标签"区分，不靠颜色。

## 4. 设施

- **庇护所**（Lv1–8）：决定淡水上限、风暴潮防御、其他设施的等级上限。升级时耐久回满。Lv8 = 方舟 = 胜利。
- **海水过滤器**（Lv1 起）：每级 0.15 淡水/秒，耗电 0.1/秒；没电时只有 30% 效率。等级 ≤ 庇护所等级 + 1。
- **电鳗发电机**（Lv0 起，庇护所 Lv2 解锁）：每级 0.25 电力/秒。每次升级需要 1 条电鳗。等级 ≤ 庇护所等级。

## 5. 打捞小游戏（单键时机）

- 海面上漂着 5 件物品，钩子准星左右往返扫动。
- 按"确认"在准星位置落钩，压中物品即捞起。每次出海 3 钩，返航后有 8 秒冷却。
- 物品权重：废料 45%、水瓶 18%、滤芯 14%、宝箱 11%、电鳗 5%、海藻（空）7%。
- 天数越大，准星越快、物品越窄。

## 6. 宝箱

- 三种：木箱 / 铁箱 / 金箱（打捞时概率 70/25/5）。
- 开箱：连按"确认"撬锁（木 2 下、铁 3 下、金 4 下），然后揭晓奖励。
- 奖励池：废料、淡水、滤芯、电鳗，金箱必出电鳗或大量滤芯。

## 7. 天数与风暴潮

- 一天 = 60 秒实时（原型值，可调）。打开菜单、打捞时时间照常流逝；结算弹窗时暂停。
- 每日结算：
  - 消耗淡水 `3 + 0.5 × 天数`（向上取整），不足部分每点扣 6 耐久。
  - 风暴潮伤害 `max(0, 天数 − 庇护所等级 × 2) × 8`。
- 耐久归零 → 庇护所沉没 → 重新开始。
- "修补"：5 废料 → +20 耐久。

## 8. 交互（Rokid Glasses 镜腿）

| 输入 | AIUI `event.code` | 作用 |
|---|---|---|
| 前/后滑 | `ArrowUp` / `ArrowDown` | 移动焦点 |
| 单击 | `Enter` | 确认 / 落钩 / 撬锁 |
| 返回 | `Backspace` | 返回上一级；主界面时交给系统关闭智能体 |

所有方向/确认键在 `onKeyDown` 即时响应，并在 `onKeyUp` 调用 `preventDefault()` 接管默认行为。

## 9. 视觉（遵循 AIUI 单色绿规范）

- 画布 480×352，安全边距 16/12px；仅用 `#40ff5e` 不同亮度（100/72/48/24/12%）。
- 1px 线框为主，焦点 = 12% 底色 + 72% 边框 + `›` 标记；不可用 = 虚线边框 + "缺料"文字。
- 庇护所用"叠层甲板"示意：每级一层，下方波浪线代表潮位。
- 不用 emoji，不用第二种颜色。

## 10. 存档

- `wx.setStorageSync('tideark.save.v1', state)`，每 5 秒及 `onHide` 时保存；`onLoad` 读取。
- 不做离线收益（v0.1）。

## 13. 世界观：深蓝纪元

> 采用用户提供的「深蓝纪元」设定作为背景。游戏名仍为《潮汐方舟》；
> 设施、角色的名字与造型都是本作原创。参考资料里的广告机关（鲨鱼搅拌机、海牛化工机、河豚制氧机）和角色形象**不沿用**，只借用角色定位。

### 13.1 背景

公元 2147 年发生「大淹没」：海平面失控上涨，城市、平原与工厂相继沉没，幸存者把此后的时代称为**深蓝纪元**。
陆地只剩零星的高塔与钻井平台，人类靠漂浮庇护所在海上生存。

### 13.2 三条生存法则（对应游戏资源）

| 法则 | 含义 | 游戏内 |
|---|---|---|
| 淡水决定生存 | 没水就会死，淡水是硬通货 | 淡水 `≈`、每日消耗、过滤器 |
| 能源决定发展 | 变异生物发电是海上主要能源 | 电力 `ϟ`、电鳗发电机 |
| 打捞决定未来 | 旧世界的残骸是一切材料来源 | 废料 `#`、滤芯 `◇`、宝箱 |

### 13.3 庇护所时代（Lv1–8）

| 等级 | 时代 | 主界面标题 | 外观 |
|---|---|---|---|
| 1–2 | 木筏时代 | 庇护所 LvN · 木筏时代 | 木板、绳子、油桶 |
| 3–4 | 生存时代 | 生存时代 | 铁皮棚、集水装置 |
| 5–6 | 电气时代 | 电气时代 | 电鳗发电机、灯、天线 |
| 7 | 工业时代 | 工业时代 | 多层钢构、吊臂 |
| 8 | 方舟 | 方舟 | 可抵御一切风暴潮的移动城邦 |

跨时代升级时消息栏提示「进入××时代」（`eraOf()`）。

### 13.4 主线（第一幕 = 当前版本）

> 下面是 v0.1 已实现的剧情节点。v0.2 扩展为三幕八章，见 [故事.md](故事.md)；角色定稿也以那里为准。

1. **序章**（首次启动）：大淹没 → 深蓝纪元 183 年，你交不起淡水配给费，被聚落赶到外海，只有一块木筏。
2. **第一枚滤芯**（首次捞到滤芯）→ **第一口淡水**（首次升级过滤器）。
3. **网里的电鳗**（首次捞到电鳗）→ **第一盏灯**（首次建发电机）。
4. **熬过风暴潮**（第一次挨风暴潮之后）。
5. **新的邻居**（庇护所 Lv6）：其他被驱逐者来投靠，庇护所开始像城邦。
6. **方舟建成**（Lv8）：无线电里传来「深蓝计划」的呼号，作为第二幕的钩子。

第二幕规划：电鳗发电机图纸 → 沉没实验室 → 深蓝计划真相。
剧情节点在 `game.js` 的 `STORY` 表；首次达成时排队，只在没有弹窗、没在打捞或撬锁时弹出，不打断操作。

### 13.5 势力

- **漂流者**：被聚落驱逐的普通人（玩家出身）。
- **海上城邦联盟**：控制淡水配给的最大势力，收「水费」。
- **深海打捞公司**：铜盔潜水员，垄断深海残骸。
- **海盗**：掠夺庇护所。
- **海兽研究会**：研究、驯养变异海洋生物。

### 13.8 生态

变异巨鲨、巨型章鱼、发光的深海生物；电鳗是最重要的能源生物。均作为打捞事件、风暴事件与第二幕敌人的素材。
