# 潮汐方舟 — 交互设计 v0.4

> 承接《系统设计》与《AIUI 能力调研》。本文件写四键操作流程、每个界面的内容、v0.3 的「居民派遣 + 聊聊」，以及 v0.4 的「行动力 + 回合制打捞」（第 0 节）。
> 全部界面截图见 [screenshots/](screenshots/README.md)，由 `node tools/shots.mjs` 自动生成。

## 0. v0.4：行动力与回合制打捞

### 0.1 为什么改

- 旧打捞是准星来回扫、按确认卡时机。眼镜的按键到画面有明显延迟，卡时机等于看运气，玩家觉得「点了没反应」。
- 旧的一天是 60 秒实时倒计时：菜单里犹豫、读剧情都在耗时间，和「随时摘下眼镜」的使用方式冲突。

### 0.2 行动力

- 每天 6 点，主界面顶栏显示 6 个格子。没有倒计时。
- 花费：近海 2、残骸带 3、沉城 4、实验室 2；建造升级、修补、开箱各 1；派遣、聊聊、交易不花。
- 菜单项副标题写花费（`行动 2`），不够时置灰；硬按会在消息栏提示「行动力不够……结束今天就能恢复」。
- 主菜单最后一项是「结束今天」，随时可按。行动力刚好用完、回到主界面时，焦点自动跳到「结束今天」（只跳一次）。
- 修补只在耐久不满时出现在主菜单。

### 0.3 打捞：选目标 + 见好就收

- 一行 5 张卡，由近到远（近 近 中 远 远），下面一行「返航」。上下移动焦点（跳过已钩过的），确认落钩，不需要卡时机。
- 近处 2 张看得清，成功率 100% / 90%；远处 3 张显示「？ 看不清」，成功率 75% / 60% / 45%，稀有物更多，巨鲨和水母只在远处。
- 剧情物（漂流者、图纸、门禁卡）总在最近的格子，标 `!`，必中，钩中立即生效。
- 普通收获先放在船上（`船上 N 件`），返航时才入库。钩中巨鲨：多断一钩、耐久 −5、叼走船上一半收获。钩中水母：剩下的「？」全部看清。
- 3 钩用完自动停在「返航」；返回键随时返航，船上的收获照样入库。

### 0.4 返回键不再替你作答

海盗夜、终章二选一、沉没三种弹窗改为「上下选择 · 确认」：返回键被吞掉，不会误交保护费、误选结局，也不会误清存档。海盗弹窗默认选中能赢的一项（打不过时默认交保护费）。沉没后默认「从第 N 天早上重来」（每天早上自动记一个重来点），另一项是「从头开始」。

## 1. 四个键

| 键 | 眼镜手势 | 作用 |
|---|---|---|
| 上 / 下 | 镜腿前滑 / 后滑 | 移动焦点；列表循环 |
| 确认 | 单击 | 进入、落钩、开箱、关闭弹窗；有选项的弹窗里确认当前选项 |
| 返回 | 返回 | 回上一级；打捞中＝提前返航；主界面上交还系统关闭；有选项的弹窗里无效 |

规则：
- 任何界面最多两层：主界面 → 列表 → 详情。返回总是回到你进来的那一项（焦点不丢）。
- 普通弹窗出现时上 / 下无效，确认 / 返回都是关闭；有选项的弹窗用上 / 下选、确认生效。
- 底部动作行写清楚这一屏的按键含义，例如 `确认 · 落钩    返回 · 返航`。

## 3. 居民：派遣与聊聊（v0.3 新增）

### 3.1 为什么做

手动打捞是唯一的主动玩法，重复多了会累。派遣让已经入住的居民替你出海：你决定**派谁、去哪**，他们回来时带着收获和一句话。打捞仍然保留，派遣是并行的第二条收入线。

### 3.2 流程

1. 主界面 `居民` → 居民列表。每行：立绘、名字、状态（`在船上` / `残骸带 · 明早回`）、好感 `●●●○○`（♥ 在眼镜上会渲染成红色 emoji）、`擅长残骸带 · 想聊聊`。出海中的居民立绘变暗、边框变虚线。
2. 确认 → 居民页。每个已解锁的打捞海域一行 `派遣 · 近海`（`不花行动 · 明早带回 2 件 · 擅长`，费用 `≈2`，状态 `可派 / 出海中 / 缺水`），最后一行 `聊聊`。
3. 在海域行按确认：扣 2 份淡水（口粮），居民出发，回到居民列表，消息栏写 `铆钉出发去残骸带了。`
4. 结束今天时，出海的居民全部归来，收获合并成结算弹窗里的一行：`派遣 2 人：#+11 ◇+1 木箱+1 · 遇鲨丢 1`。
5. 在 `聊聊` 按确认：弹出居民立绘和一句话，下面是好感。

### 3.3 数值

| 项 | 值 |
|---|---|
| 派遣耗时 | 当晚结算时归来（每人每天一趟） |
| 口粮 | 淡水 2 |
| 带回件数 | 1；去擅长海域 +1；好感 ≥3 再 +1 |
| 掉落 | 该海域掉落表，去掉剧情物（图纸、门禁卡、漂流者）；巨鲨＝丢一件 |
| 好感 | 0–5；每次派遣归来 +1；每天第一次聊聊 +1 |
| 同时出海 | 每位居民一次一趟，人数不限 |

擅长海域：珊瑚、小锅＝近海；铆钉、铁梁、灯塔叔＝残骸带；锈锚、气泡＝沉城。

派遣归来并进每日结算，不再单独弹窗；存档里只记谁去了哪片海。

### 3.4 台词：固定台词 + 可选大模型

- 每位居民在 `game.js` 的 `CREW` 里写了 3 句闲聊、1 句危险夜提醒、1 句归来台词。聊聊按次数轮换；**今晚有风暴伤害或海盗时，优先说提醒**。
- 弹窗先显示写好的台词。页面随后检查 `LanguageModel.availability()`：
  - `available`：用 `talkPrompt()` 生成提示（人设 + 第几天、耐久、淡水、危险夜 + 这次要说什么），`promptStreaming()` 流式替换那一行，限 16 字。
  - 其他情况（预览、没网、配额用完、出错）：保留写好的台词。
- 台词定下后用 `speechSynthesis.speak(…, 'immediate')` 以居民音色读一遍；不支持就跳过。
- **大模型只负责措辞**：收获、好感、扣水全部在 `game.js` 里先算好，模型看到的是结果，不能改结果。

### 3.5 暂不做

- 语音输入（ASR）聊天：要 `RECORD_AUDIO`，且只能由按键触发；先验证 LLM 在真机上的延迟再做。
- 关闭游戏后继续计时：AIUI 不支持后台运行；v0.4 改成按天结算，不再需要。
- 模型工具调用（推荐派遣海域等）。

## 4. 主界面行数

主菜单最多 7 项（出海、建造、宝箱、居民、修补、秤砣、结束今天）。超过 5 项时切到紧凑行（行高 26px、图标 22px），保证目标行 + 7 项放得下 480×352（见截图 28-tired）。
